反馈与支持  
===  

简历制作工具（Resume Revise）是一款原生 Mac 应用，提供可视化编辑器，帮助您根据求职需求和个人风格定制简历。无需登录，您的信息保留在 Mac 本机。

您的反馈和支持非常重要！如果您遇到问题、有疑问或希望提出新功能建议，欢迎随时联系我们。您的意见将帮助我们持续改进简历制作工具。

您可以通过 GitHub 或发送邮件至 **kennyiseeyou@gmail.com** 联系我们。感谢您选择简历制作工具！
